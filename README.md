# 脱毛カレンダー

家庭用脱毛器での照射記録をカレンダー形式で管理するシンプルな Web アプリです。ビルド不要で、`index.html` をブラウザで開くだけで使えます（GitHub Pages などにそのまま置くこともできます）。

## 機能

- **月間カレンダー**：照射した日に部位がチップで表示されます（`左`＝青、`右`＝オレンジ、`両`＝紫）。
- **左右の選択**：ワキ・ひじ下・ひざ下など左右のある部位は「左」「右」を個別に選べます。両方選ぶと「両側」として記録されます。
- **記録内容**：日付・使用した脱毛器（前回の値を自動入力）・部位・部位ごとの出力レベル（その部位の前回レベルを自動入力）・メモ。
- **部位別サマリー**：左右別に照射回数・前回日と出力レベル・次回目安日（設定した間隔、初期値14日）を一覧表示。目安日を過ぎた部位は赤で表示。
- **部位のカスタマイズ**：部位の追加（グループ名・左右あり/なし）、並べ替え、削除。記録で使われている部位は記録を残すため「非表示」になります。
- **データのバックアップ**：JSON でエクスポート/インポート。

## データの保存先

データはブラウザの `localStorage` に保存されます。端末やブラウザを変えるとデータは引き継がれないため、必要に応じてエクスポートでバックアップしてください。

## ファイル構成

- `index.html` — 画面構成
- `style.css` — スタイル（ダークモード対応）
- `app.js` — ロジック
